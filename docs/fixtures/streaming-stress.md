# 十二、结算后看什么
1. 快速滚动：正文中段是否有空白带、重叠、或内容整体跳一段距离。
2. 顶部停留：流式期间视口停在正文最上面，尾部是否仍在持续长高且不闪。
3. 宽度拖动：改变宽度后一帧内内容是否重排到位，没有任何旧高度的残留。
4. 搜索：开一次搜索，整段应退回全量遍历，命中定位应落在正确行上。
5. 批注：如果上批注标记，行为应与搜索一致。
6. 巨型单块：结尾那个 120 行围栏与超长段落是否都能完整滚到底，没有裁切。
7. 单个巨型列表：第十一节整段只有一个块，滚动时确认没有裁切、没有接缝，也没有额外停顿（它本来就不可能被窗口化）。

| ---------------- | ------------ | -------------------------- |
| 正文中段快速滚动 | 无空白带     | 出现竖直空白或错位接缝     |
| 顶部停留         | 尾部持续长高 | 尾部延迟一行或闪烁         |
| 宽度拖动         | 一帧重排到位 | 旧高度残留、块之间出现缝隙 |
| 搜索命中         | 定位正确     | 命中处空白或跳错位置       |
| 巨型单块         | 完整滚动     | 底部被裁切或行距抖动       |
